Manajemen Database & Keberlanjutan Data Arsip

Agar aplikasi buku tamu desa ini dapat dipakai berkelanjutan bertahun-tahun tanpa risiko kehilangan data, Anda disarankan mengunduh berkas cadangan (backup JSON) secara rutin (misal setiap akhir pekan atau akhir bulan) dan menyimpannya di Flashdisk atau Google Drive Kantor Desa Sukarame.

Unduh Cadangan (Backup JSON)

Simpan seluruh arsip pendaftaran ke file mandiri.

File backup berisi seluruh data riwayat registrasi surat, nama warga pemohon, tanggal, serta status arsip dalam format JSON standar.

Pulihkan Data (Restore JSON)

Muat kembali data arsip dari file cadangan sebelumnya.

Gunakan fitur ini jika berpindah komputer kantor atau setelah melakukan instalasi ulang peramban.

Pengaturan Identitas Default Staf Pelayanan

Nama ini akan otomatis terisi setiap kali membuka formulir pelayanan baru.

Zona Berbahaya: Kosongkan Seluruh Data Arsip

Hanya lakukan saat memulai tahun baru atau uji coba awal. Pastikan sudah mengunduh backup!
